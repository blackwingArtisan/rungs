# Rungs

## Standard

This repository is public and is read as a portfolio. Every change ships polished:
- Clean, readable code; the tests (`cd contract && cargo test`) pass before every commit.
- Professional wording everywhere a reader looks: code, comments, docs, commit messages, branch names.
- Sample data uses invented people, businesses and addresses.
- Internal notes, ticket keys, local paths, keys, seed phrases and personal details stay out of the repo.
- Work lands on `main` through short-lived branches that are deleted after merging; `gh-pages` serves the site.
